## Описание проекта

Система предназначена для цифровизации процесса подачи, распределения и обработки официальных обращений и заявлений студентов деканатом Института цифровых технологий и экономики (ИЦТЭ) КГЭУ.

### Основные сущности и процесс:
1. **Студент** формирует обращение по конкретной услуге из справочника (заказ академической справки, перевод, вопрос по стипендии или задолженности).
2. **Заместитель декана** распределяет поступившие обращения и назначает ответственного сотрудника деканата отдельным действием.
3. **Сотрудник деканата** принимает закреплённое обращение в работу (`InProgress`) и после подготовки ответа/документа переводит его в статус `Closed` либо `Cancelled`.
